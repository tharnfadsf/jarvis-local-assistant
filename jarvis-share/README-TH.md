# วิธีแชร์โปรเจกต์ J.A.R.V.I.S. (ภาษาไทย)

โฟลเดอร์นี้ (`jarvis-share/`) คือชุดไฟล์ที่พร้อมส่งต่อแล้ว
โค้ดไม่มีการแก้ไข เป็นสำเนาที่คัดมาเฉพาะไฟล์ที่ต้องใช้

> อย่าส่งโฟลเดอร์ `i-w` ทั้งโฟลเดอร์ — ข้างในมีคีย์ลับ (`.env`),
> ข้อมูลส่วนตัว, ไฟล์โมเดลเสียง (~95 MB) และโฟลเดอร์ backup หลายร้อยอัน
> ส่งเฉพาะโฟลเดอร์ `jarvis-share` นี้เท่านั้น

## วิธีที่ 1: ส่งเป็นไฟล์ zip (ง่ายที่สุด)

1. คลิกขวาที่โฟลเดอร์ `jarvis-share` → Send to → Compressed (zipped) folder
2. ส่งไฟล์ `jarvis-share.zip` ให้เพื่อนทาง Discord / Line / Drive ได้เลย
3. เพื่อนแตก zip แล้วอ่านไฟล์ `README-TH.md` (ไฟล์นี้) ต่อ

## วิธีที่ 2: ส่งผ่าน Discord webhook (อัตโนมัติ)

1. ใน Discord: เปิด Server Settings → Integrations → Webhooks → New Webhook
   เลือกห้องที่จะส่ง แล้วกด Copy Webhook URL
2. ดับเบิลคลิกไฟล์ `Send-To-Discord.ps1` ในโฟลเดอร์นี้
   (หรือคลิกขวา → Run with PowerShell)
3. วาง Webhook URL ตอนที่สคริปต์ถาม (สคริปต์จะไม่บันทึก URL ไว้ที่ไหน)
4. สคริปต์จะ zip โฟลเดอร์ ตรวจสอบว่าไม่มีไฟล์ลับ (`.env` / โมเดลเสียง)
   หลุดไป แล้วอัปโหลดเข้า Discord ให้เอง

## เพื่อนที่ได้รับต้องทำอะไรต่อ

1. แตกไฟล์ zip
2. ก็อปปี้ `copy .env.example .env` แล้วใส่คีย์ของตัวเอง
   (ห้ามขอไฟล์ `.env` ของคุณ — ให้เขาสร้างของตัวเอง)
3. เอาโฟลเดอร์ `offline-asr/models/` และ `offline-asr/runtime/`
   จากเครื่องที่มี J.A.R.V.I.S. มาวางตามโครงเดิม
   (ดูรายละเอียดใน `offline-asr/README.md`)
4. ติดตั้ง Node.js + Microsoft Edge, ติดตั้ง Ollama (ถ้าจะใช้ AI)
   วิธีละเอียดอยู่ใน `README.txt`
5. ดับเบิลคลิก `Start-Jarvis.bat` แล้วอนุญาตไมโครโฟน
   พูดว่า “Jarvis, open Steam” เพื่อทดสอบ

## ข้อควรระวัง

- ห้ามส่งไฟล์ `.env` ของคุณให้ใคร (มี API key)
- ห้ามส่งทั้งโฟลเดอร์ `i-w` (ใหญ่และมีข้อมูลส่วนตัว)
- ถ้าเคยวาง Webhook URL ลงในแชต ให้ลบแล้วสร้างใหม่อย่าใช้ซ้ำ

## เคล็ดลับการสั่งงานด้วยเสียง

- ไม่ต้องพูดคำว่า open ทุกครั้งก็ได้ พูดแค่ชื่อแอปก็พอ
  เช่น “Jarvis, Steam” ก็เปิด Steam ให้เลย ใช้ได้กับแอปทั่วไป
  เบราว์เซอร์ เกม และเว็บ (เช่น “Jarvis, YouTube”)
- ถ้าอยากเปิดแอปอื่นที่ไม่ได้อยู่ในรายการทางลัด
  ให้พูดแบบเดิมว่า “open …” ได้ตามปกติ
