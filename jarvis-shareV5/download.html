J.A.R.V.I.S. Share

Cross-platform desktop assistant — Windows, macOS & Arch Linux

v1.0.0

Requirements

●
Node.js 18+ Required to run the JARVIS server. Download
●
Chromium Browser Chrome, Edge, or Brave for tab control features.
●
Ollama (optional) For local AI. Download then run ollama pull qwen3:1.7b
●
Microphone For voice commands and wake-word detection.

Installation Steps

Download

Select your platform above and download the appropriate package.

Extract / Install

Windows: Run the .exe installer or extract the ZIP.
macOS: Open the .dmg and drag JARVIS.app to Applications, or extract the ZIP.
Arch Linux: sudo pacman -U jarvis-share-*-x86_64.pkg.tar.zst (native package) or run the AppImage.

Configure in the app

No file editing needed. On first launch the setup wizard opens: pick your AI provider (local Ollama or an external API), paste your API key, and press Test Connection. Everything can be changed later from the ⚙ SETUP button in the app.

Launch

Windows: Run Start-Jarvis.bat.
macOS: Run ./start-jarvis.sh or open JARVIS.app.
Arch Linux: Launch J.A.R.V.I.S. Share from your application menu, or run jarvis-share in a terminal.

Enable Voice

Allow microphone access, click "ENABLE VOICE", then say "Jarvis, open Chrome" to test.

Important Notes

  • No personal data included: This package contains no API keys, conversation history, browser profiles, or private configuration.
  • First run: Creates local data folders in your user directory (%LOCALAPPDATA%\JARVIS on Windows, ~/Library/Application Support/JARVIS on macOS).
  • Offline speech: The offline-asr/ folder with Whisper model and runtime is now included in the package. Local voice recognition works out of the box — no need to copy files from another install.
  • Browser control: Say "enable browser control" to connect JARVIS to Chrome/Edge for tab management.
  • Security: No Roblox cookies, browser sessions, or credentials are collected or transmitted. All processing is local.
